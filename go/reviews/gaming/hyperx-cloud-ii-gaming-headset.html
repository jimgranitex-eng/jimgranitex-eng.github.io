Buyer questions, answered

Does it work on PS5/Xbox?
Yes — 3.5mm for controllers, USB sound card for PC/PS. Check the listing for current console compatibility.

Is the mic detachable?
Yes — detach it and the Cloud II becomes regular closed-back headphones.

Virtual surround helps some players with positional audio; others prefer stereo. It's toggleable, so try both.
